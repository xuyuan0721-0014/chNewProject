# 乌贼文风·剑烛大荒 写作技能

**适用**：穿越者朱希言附身守村人朱大胆，写实中式民俗恐怖，鬼怪真实存在。世界观、鬼怪规则以仓库 `CLAUDE.md`、`交接文档.md`、`鬼.md`、`主线.md` 为准。本技能只管笔法，不新增、不篡改设定。

**文件**：本文件是总纲，每条一句话。每条的原著出处、行号、例句和统计在 `references/` 里，写到哪类段落，先读对应的细则：

| 写什么 | 读哪份 |
| --- | --- |
| 叙述口吻、打趣、心里话、推理、写景、标点分段、用词、句式、节奏、章头章尾 | `references/口吻与句法.md` |
| 人出场、到新地方、物件、民俗流程、看见要紧东西 | `references/白描.md` |
| 对白领起、话的长短、对白前后写什么、各人口吻 | `references/对话.md` |
| 情绪、旁人起疑 | `references/情绪.md` |
| 异象、恐怖、民俗器物、跟人打、跟死律挣命、斗法 | `references/异象与打斗.md`，另有古籍 `参考/斗鬼语料.md` |
| 切视角、全书第一章、每卷开头、格式、字数、章节标题 | `references/视角开篇格式.md` |

细则里说“第X节第Y条”，指的是这些文件里同名的小节（一、一之二、三……），节号和本文件一致。原著文件是仓库根目录 `剑烛大荒（爱潜水的乌贼）.txt`（有的电脑上名为 `《剑烛大荒》作者：爱潜水的乌贼.txt`，行号相同）和 `捞尸人.txt`。

## 零、动笔前（最高优先级）

1. **先读原著**：动笔前读《剑烛大荒》里与这一章同类的章节（醒来、认人、查案、斗嘴、异象、推理），写的时候拿原著的一段在旁边对着。
2. **不用旧稿**：删掉的稿子不翻 git 历史看，不拿来核对情节，不沿用字句桥段。按本技能写成、仍在仓库里的定稿，可以逐段修改。
3. **禁抄**：不照搬两部原著有辨识度的东西：成句的描写和比喻、整段对白、桥段、人物和设定名词。通用说法和提示语套式（“语带恐惧，略显颤抖地说道”“若有所思地问道”“念头急转”“不动声色”）可以用。
4. **衔接**：续写接上前文定稿，人物状态、伤、物件、情绪都要接得上。

## 一、口吻（细则：`references/口吻与句法.md`）

1. 叙述半文半白，平实，不雕；土话只在配角嘴里，主角想事用现代口语。
2. 写人直接写神情、情绪，一个词交代，至多补一个动作；不把一个情绪拆成一串慢镜头。
3. 比喻极少，一章合计不超过三处，多用现成说法；打斗章可放宽。
4. 叙述者会插话打趣（揭底、点破、反话、旁人会错意、拿前世比），每章几处，紧贴它打趣的那句话，不放在最吓人的那一刻。
5. 主角的心里话用“我”，不加引号，当场冒出来；单独成段和跟着神态动作同段两种轮着用。
6. 推理是自问自答，只用看见的、听见的、别人说的，末尾落到一句话或一个动作上。
7. 写景是交代信息：跟着人走，有顺序，带天光，写完接主角一句反应；造气氛的句子只放在异象之前，一处。
8. 过场一笔带过，但这一笔写满；慢下来只给异象、打斗、情绪真正起伏的那一刻。
9. 一段一句（叙述、对话都是）；多句段只出在心里话上。省略号只给没说完的话；对白里叹号少用；不用破折号。
10. 用词偏书面：叙述里“未”“没”各半，“将”多于“把”，常用于、已、而、竟、皆；原著不用的词换成原著的说法，拿不准就去原著里搜。
11. 句式：“V了下”“V了V”都用，“……间，”“见……，”起句，“V起”带宾语，段首用名字和用“他”大致各半。
12. 节奏：章头接住上一章最后那句；章尾停在新露头的东西上，前文已交代的就停在那句话上，收住就走；一章多半一个场面；主角想事时旁人不停。

## 一之二、白描：一句写满（细则：`references/白描.md`）

一句写完一串动作，写到结果；到新地方先环顾，再按方位点实物；人一出场，一句写完衣着、头发、长相、年纪、手上的事；物件带颜色材质新旧；民俗流程写到手上的东西和次数；天光风声挂在到场和行走里；看见要紧东西，先有感觉，再看见，再补特征。不写只剩一个动作的秃句。

## 二、视角（细则：`references/视角开篇格式.md`）

以朱希言为锚；每卷前几章（第一卷前九章）、独处、推理不切视角；别方插段千字内，正文用独立一行「…………」隔开；破局、生死、转折落在朱希言身上。

## 三、对话（细则：`references/对话.md`）

1. 领起三种轮着用：冒号领起、先说后补、补在话中间；长话多先领起，短话多先说后补。
2. 不写光秃秃的“说：”“说道：”“他道”“她道”；领起那一段短，一两样东西。
3. 几乎每句话都挂着人：怎么说、为什么说、说完怎样、听的人怎样；动作神态冲着对面那个人。光对白极少。
4. 话的长短跟着人和事走，不数字数：讲规矩、交代来由、劝人骂人的话说全；一问一答、斗嘴照人说话的样子短。
5. 要紧的话落地，接着拆它；主角开口有盘算。
6. 声音挂在说话的人身上，用“嗓音”；看不见人时用“有人”或“一道……的嗓音响起”。
7. **一人一个口吻**：固定的称呼反复用（叫错称呼就露馅），自称敬称看身份，身份年纪定文白和长短，各人说各人知道的，一两个口头小记号；土话只撒一点，一场戏一个人一两处；主角嘴上不带土词。

## 四、情绪（细则：`references/情绪.md`）

情绪直接写，点出名目，点完就走；每挨一句话脸变一次；真情露出来又遮回去；重话说得淡；物件装情绪、跨章收回；情绪有惯性；主角的情绪直说带自嘲；旁人起疑要说出口，借口也说出口，不拿意味深长的眼神代替。

## 五、异象、民俗与打斗（细则：`references/异象与打斗.md`、`参考/斗鬼语料.md`）

1. 恐怖只放在异象出现的地方；叙述者只摆实相，不解释、不预判、不贴标签，判断留给人物。
2. 先认错再认出；反常先行一处；声音先到；一眼一眼逼近；熟人熟物变了样；旁人比主角先怕，怕得有来由；规矩时灵时不灵；有余悸。异象写完立刻回到乌贼的口吻。
3. 民俗器物有名目、有先后，每一步配一句讲究，是营生也是人情；白泽图只显类别与规矩，不给破法。
4. 打斗一招一段、写到结果，有来有回；跟人打先交底，主角靠嘴、脑子、土法，赢得难看；跟死律挣命写拉扯、旁人各干一件、土法有灵有不灵；斗法一步步写怎么做，施术人身上跟着变，效果打折扣；斗完先查人，留账到下一章。

## 六、开篇与格式（细则：`references/视角开篇格式.md`）

全书第一章照原著的次序（短梦、一声响、写实、压出主角、吐槽、人声先到、看清处境、前世阅历派上用场、身上的证据）；每卷开头先盘点身上多了什么少了什么。段首两格全角空格，中文引号“”，单章 2500–3500 字，章节标题多两字或四字，常用成语反着用，不重名、不用原著用过的。

## 八、黑名单

1. 不写“下意识”“本能地”“莫名感觉”这类天降认知；原身记忆不自动浮现，他知道的每件事都要有来处。
2. 不写光秃秃的“说：”“说道：”“他道”“她道”。
3. 不照搬原著有辨识度的句子、段落、桥段（第零节第 3 条）；通用说法和提示语套式不在此列。
4. 不改剧情钩子、人设、鬼怪设定。
5. 不写“阴森”“诡异”“死寂”“空气凝固”“毛骨悚然”这类氛围标签，不写大段抒情。
6. 不用破折号。
7. 不用西式克苏鲁符号、数值理智、触手。
8. **AI 腔清单**（写完逐条查）：
   - 一个情绪拆成手、眼、脚一串慢镜头；
   - 比喻一章超过三处（打斗章可以放宽，只用现成说法）；
   - “慢慢”“缓缓”“好一会儿”“好几息”一章用了不止一次，或用了“一点一点”；
   - “没去看 A，先 B，才 C”这种排好的动作顺序；
   - 三连排比（坑是真的，土是真的，肉也是真的）、段末金句；
   - 景物句句在铺气氛；
   - 叙述一口土话，或配角句句土词；
   - 一整章没有一句叙述者的打趣、没有几行主角的碎心里话；
   - “干”对白：挂了提示语，却只有“某某道”“某某问道”，前后没有神态、语气、用意、反应；
   - 自顾自的提示语：动作神态只在说话人自己身上，跟听话的人没有来往；
   - 意味深长的眼神、停顿、收回的手：旁人起了疑或动了情，拿一个不说破的动作代替说出口的话；
   - 该长的话掐成半句，或一问一答也硬塞理由撑长；
   - 句句“某某道：”再接一句话，短话也用领起，读起来板；
   - 几个配角说话一个腔调，换了名字分不出是谁；
   - 秃句白描：叙述段只剩一个动作；人出场没有衣着；到了新地方不环顾；物件没有颜色和材质。

## 九、写完自检

1. 拿原著同类的一段对着读，口吻像不像：平实、半文半白、爱打趣？
2. 逐段数句号：叙述段、对话段是不是都一段一句？段首短句后面有没有接着写？
3. 写人的地方，是不是直接交代了神情情绪，而不是一串慢镜头？
4. 比喻数一数，超过三处删（打斗章放宽，但只用现成说法）。
5. 叙述者有没有插话打趣？主角有没有隔几段冒一句心里话？心里话是不是都用“我”？两种落法是不是轮着用？
6. 推理是不是自问自答、有据可依、落到一句话或一个动作上？
7. 景物是在交代信息，还是在铺气氛？恐怖是不是只放在异象那几处？
8. 过场有没有一笔带过？这一笔有没有写满？
9. 白描：叙述段中位有没有到 30 字上下、超过 40 字的有没有三成上下？人出场有没有衣着、头发、长相？到新地方有没有环顾、按方位点实物、交代天色？物件有没有颜色材质？民俗流程有没有写到手上的东西和次数？
10. 对白：有没有光秃秃的“说：”？挂提示语的对白前后有没有写人？话的长短合不合这个人此刻的处境？短话是不是多用先说后补？话里带出的新名目，后面有没有人拆它？
11. 口吻：每个配角对主角的称呼是不是固定的？把名字遮住，读得出是谁在说吗？土词一个人一场戏有没有超过一两处？主角嘴上有没有土词？
12. 有没有破折号、氛围标签、天降认知？查一遍原著不用的词。
13. 有没有一处前埋后翻？有没有攒下一点暖意，或让一件旧物件带着情绪回来？
14. 每个出场的人刚经历了什么，身上还剩多少？
15. 有打斗的章：一招一段、写到结果？有来有回？跟人打有没有交底，主角赢得难不难看？跟死律挣命有没有土法灵与不灵、旁人各干一件、脱身后先查人？斗法有没有写出怎么做、施术人身上变了什么、效果打了多少折扣？
16. 章头有没有接住上一章最后那句？章尾是不是停在新露头的东西上、收住就走？字数在 2500–3500 之间吗？
