# 乌贼文风·剑烛大荒 写作技能

**适用**：穿越者朱希言附身守村人朱大胆，写实中式民俗恐怖，鬼怪真实存在。世界观、鬼怪规则以仓库 `CLAUDE.md`、`交接文档.md`、`鬼.md`、`主线.md` 为准。本技能只管笔法，不新增、不篡改设定。

**文件**：本文件是总纲，每条一句话。每条的原著出处、行号、例句和统计在 `references/` 里，写到哪类段落，先读对应的细则：

| 写什么 | 读哪份 |
| --- | --- |
| 叙述口吻、打趣、心里话、推理、写景、标点分段、用词、句式、节奏、章头章尾 | `references/口吻与句法.md` |
| 人出场、外貌、到新地方、物件、民俗流程、看见要紧东西、人物动作 | `references/白描.md` |
| 报时、赶路、量远近高低、买卖给钱 | `references/时辰距离钱数.md` |
| 主角做决定、开口、想事，身上露出老道士的习惯 | `references/主角性格.md` |
| 对白领起、话的长短、对白前后写什么、各人口吻、多人场面 | `references/对话.md` |
| 情绪、神态、旁人起疑 | `references/情绪.md` |
| 异象、恐怖、民俗器物、跟人打、跟死律挣命、斗法 | `references/异象与打斗.md`，另有古籍 `参考/斗鬼语料.md` |

## 零、动笔前（最高优先级）

1. **先读原著**：动笔前读《剑烛大荒》里与这一章同类的章节（醒来、认人、查案、斗嘴、异象、推理），写的时候拿原著的一段在旁边对着。
2. **不用旧稿**：删掉的稿子不翻 git 历史看，不拿来核对情节，不沿用字句桥段。按本技能写成、仍在仓库里的定稿，可以逐段修改。
3. **禁抄**：不照搬两部原著有辨识度的东西：成句的描写和比喻、整段对白、桥段、人物和设定名词。通用说法和提示语套式（“语带恐惧，略显颤抖地说道”“若有所思地问道”“念头急转”“不动声色”）可以用。
4. **衔接**：续写接上前文定稿，人物状态、伤、物件、情绪都要接得上。

## 一、口吻（细则：`references/口吻与句法.md`）

1. 叙述半文半白，平实，不雕；土话只在配角嘴里，主角想事用现代口语。
2. 写人直接写神情、情绪，一个词交代，至多补一个动作；不把一个情绪拆成一串慢镜头。
3. 比喻极少，一章合计不超过三处，多用现成说法；打斗章可放宽。
4. 叙述者会插话打趣（揭底、点破、反话、旁人会错意、拿前世比），每章几处，紧贴它打趣的那句话，不放在最吓人的那一刻。
5. 主角的心里话用“我”，不加引号，当场冒出来；单独成段和跟着神态动作同段两种轮着用。
6. 推理是自问自答，只用看见的、听见的、别人说的，末尾落到一句话或一个动作上。
7. 写景是交代信息：跟着人走，有顺序，带天光，写完接主角一句反应；造气氛的句子只放在异象之前，一处。
8. 过场一笔带过，但这一笔写满；慢下来只给异象、打斗、情绪真正起伏的那一刻。
9. 一段一句（叙述、对话都是）；多句段只出在心里话上。省略号只给没说完的话；对白里叹号少用；不用破折号。
10. 用词偏书面：叙述里“未”“没”各半，“将”多于“把”，常用于、已、而、竟、皆；原著不用的词换成原著的说法，拿不准就去原著里搜。
11. 句式：“V了下”“V了V”都用，“……间，”“见……，”起句，“V起”带宾语，段首用名字和用“他”大致各半。
12. 节奏：章头接住上一章最后那句；章尾停在新露头的东西上，前文已交代的就停在那句话上，收住就走；一章多半一个场面；主角想事时旁人不停。

## 一之二、白描：一句写满（细则：`references/白描.md`）

一句写完一串动作，写到结果；到新地方先环顾，再按方位点实物；人一出场，一句写完衣着、头发、长相、年纪、手上的事；物件带颜色材质新旧；民俗流程写到手上的东西和次数；天光风声挂在到场和行走里；看见要紧东西，先有感觉，再看见，再补特征。不写只剩一个动作的秃句。

## 一之三、人物动作（细则：`references/白描.md`）

情绪落在脸上、眼里、脑袋上（望向、侧头、点头、眯眼、表情一变），手去干活（拿、推、递、接过），不拿攥、搓、跺、拍去填领起；动作小，带“微”“略”；常见反应是先一怔、一呆，再变；目光有去向，在人之间走；动作带用意，同一句写出来；可以好笑；礼数合身份。

## 一之四、人物外貌（细则：`references/白描.md`）

出场一段写完，按年纪身份、头发冠巾、衣裳、一两处五官、一句总评、手上拿的走；衣冠叫得出明代的名目，颜色说细，不写“褂子”；五官挑一两处带点怪的，可藏线索；年纪写估的，主角用现代尺子量；画完拿最显眼的一样当称呼；再出场写换了什么；看得清才写。

## 一之五、时辰、距离、钱数（细则：`references/时辰距离钱数.md`）

短等待写“几息”，赶路办事写“一刻”“半个时辰”，报花了多久；干支时刻（申正、子正）多在对白里，是约定、作证的口径，夜里借打更声进场；村里人只看天光、鸡叫、饭点，时辰名目只在讲究里和懂行的人嘴里；近处量步，高处量丈，量人用尺，远路说里，前世的尺子只在主角心里目测时用；钱挂在人身上，买卖写出价钱，比价交代一次，价钱一出主角有反应；价照 `时代.md`；数字用汉字。

## 一之六、主角性格（细则：`references/主角性格.md`）

朱希言的底子是谨慎、爱盘算、拿失忆当盾也当刀，决定回到上班族的阅历上；**不嘴贫**，嘴上话少不抖机灵，打趣归叙述者，心里的自嘲少而短；性子隔一章露一回，靠心里话，叙述者的标签贴在他正做这件事时；往老道士那边靠是很多章里不知不觉地渗进去，靠习惯、本事、配角的话、他自己的感觉，不点破，前期他没反应过来是性格的事，旁人先说出口，他看得见的就当回事、想不通就记着，不找借口、不搪塞，后期他才反应过来，成批收，怕的是自己。

## 二、视角（细则：`references/视角开篇格式.md`）

以朱希言为锚；每卷前几章（第一卷前九章）、独处、推理不切视角；别方插段千字内，正文用独立一行「…………」隔开；破局、生死、转折落在朱希言身上。

## 三、对话（细则：`references/对话.md`）

1. 领起三种轮着用：冒号领起、先说后补、补在话中间；长话多先领起，短话多先说后补。
2. 不写光秃秃的“说：”“说道：”“他道”“她道”；领起那一段短，一两样东西。
3. 几乎每句话都挂着人：怎么说、为什么说、说完怎样、听的人怎样；动作神态冲着对面那个人。光对白极少。
4. 话的长短跟着人和事走，不数字数：讲规矩、交代来由、劝人骂人的话说全；一问一答、斗嘴照人说话的样子短。
5. 要紧的话落地，接着拆它；主角开口有盘算。
6. 声音挂在说话的人身上，用“嗓音”；看不见人时用“有人”或“一道……的嗓音响起”。
7. **一人一个口吻**：固定的称呼反复用（叫错称呼就露馅），自称敬称看身份，身份年纪定文白和长短，各人说各人知道的，一两个口头小记号；土话只撒一点，一场戏一个人一两处，称谓口语随主角所在地区换（第一卷偏北方）；主角嘴上不带土词。
8. **多人场面**：人一个一个进场，进一个画一个；实际是两人一对轮着说，谁对谁说写清楚；每人各干一件事；不说话的人也给一句在干什么，常拿来打趣；主角多听少说，心里给每个人下判断；读者已知的事，旁人转述一笔带过；少用“众人”一起反应。

## 四、情绪与神态（细则：`references/情绪.md`）

情绪直接写，点出名目，点完就走；每挨一句话脸变一次；真情露出来又遮回去；重话说得淡；物件装情绪、跨章收回；情绪有惯性；主角的情绪直说带自嘲；旁人起疑要说出口，借口也说出口，不拿意味深长的眼神代替。

**神态**：多挂在提示语里，一个词，一章里不重样；变化写成“表情/神情/脸色＋一X”一句收住；笑分苦笑、失笑、讪笑、冷笑各有用处，笑比哭多；“一副……的样子”多用来打趣；主角的神态常是装的，叙述者点破；有人神情如常拿来反衬。

## 五、异象、民俗与打斗（细则：`references/异象与打斗.md`、`参考/斗鬼语料.md`）

1. 恐怖只放在异象出现的地方；叙述者只摆实相，不解释、不预判、不贴标签，判断留给人物。
2. 先认错再认出；反常先行一处；声音先到；一眼一眼逼近；熟人熟物变了样；旁人比主角先怕，怕得有来由；规矩时灵时不灵；有余悸。异象写完立刻回到乌贼的口吻。
3. 民俗器物有名目、有先后，每一步配一句讲究，是营生也是人情；白泽图只显类别与规矩，不给破法。
4. 打斗一招一段、写到结果，有来有回；跟人打先交底，主角靠嘴、脑子、土法，赢得难看；跟死律挣命写拉扯、旁人各干一件、土法有灵有不灵；斗法一步步写怎么做，施术人身上跟着变，效果打折扣；斗完先查人，留账到下一章。

## 五之三、伏笔与回收（细则：`references/伏笔与回收.md`）

埋在最平常的场面里，叙述者不打招呼；主角看见了，当场给一个说得通、常常好笑的解释；一条线埋几回，回回无害；短线一两章收，长线十几章收，物件跨卷；收线常成批，复述当时的细节，认下漏看，带一句打趣，末尾开出新问题；收了还有余响；藏着底细的人，让底细从吃饭、走路这类小事里露一下，带一层反差，不点破。

## 五之四、金手指露面（细则：`references/金手指.md`）

头一回只给一眼，先见字再认出是什么，章尾停在那一眼上；主角先一怔、自嘲，马上盘算风险，喜过之后浇冷水，落到下一步；显字另起一段、引号括起，挑几条，跳过的用“……”；只给类别和规矩，破法靠推、靠旁人；藏着，有人靠近就紧张；试规矩一条假设一条验证，每步一个结果，有代价；往后查页只闪一两行。

## 五之五、设定怎么交代（细则：`references/设定交代.md`）

名目先挂在看得见的东西上，再由旁人一两句点破，只说跟眼前相干的那一截；说的人带自己的身份口气，只说到自己知道的地方；主角问一句、拿前世对上，新名词先按下；大段设定只给张得开嘴的人，讲设定就是在逼主角做决定；拼图式的一块块凑，一卷至多归纳一次，放在过场里，归纳完立刻出事；叙述者只补日常小事；作者的术语（死律、亡鬼等）不从村里人嘴里出来。

## 六、开篇与格式（细则：`references/视角开篇格式.md`）

全书第一章照原著的次序（短梦、一声响、写实、压出主角、吐槽、人声先到、看清处境、前世阅历派上用场、身上的证据），认下穿越以前不提“原主”“原身”；每卷开头先盘点身上多了什么少了什么。段首两格全角空格，中文引号“”，单章 2500–3500 字，章节标题多两字或四字，常用成语反着用，不重名、不用原著用过的。

## 八、黑名单

1. 不写天降认知：拿“下意识”“本能地”“莫名感觉”让他知道本不该知道的事；原身记忆不自动浮现，他知道的每件事都要有来处。顺手的动作写“下意识”可以，原著用了二十来次（“下意识问了一句”L73，“下意识望向那面简陋的屏风”L459）。
2. 不写光秃秃的“说：”“说道：”“他道”“她道”。
3. 不照搬原著有辨识度的句子、段落、桥段（第零节第 3 条）；通用说法和提示语套式不在此列。
4. 不改剧情钩子、人设、鬼怪设定。
5. 不写“阴森”“诡异”“死寂”“空气凝固”“毛骨悚然”这类氛围标签，不写大段抒情。
6. 不用破折号。
7. 不用西式克苏鲁符号、数值理智、触手。
8. **AI 腔清单**（写完逐条查）：
   - 一个情绪拆成手、眼、脚一串慢镜头；
   - 比喻一章超过三处（打斗章可以放宽，只用现成说法）；
   - “慢慢”“缓缓”“好一会儿”“好几息”一章用了不止一次，或用了“一点一点”；
   - “没去看 A，先 B，才 C”这种排好的动作顺序；
   - 三连排比（坑是真的，土是真的，肉也是真的）、段末金句；
   - 景物句句在铺气氛；
   - 叙述一口土话，或配角句句土词；
   - 一整章没有一句叙述者的打趣、没有几行主角的碎心里话；
   - “干”对白：挂了提示语，却只有“某某道”“某某问道”，前后没有神态、语气、用意、反应；
   - 自顾自的提示语：动作神态只在说话人自己身上，跟听话的人没有来往；
   - 意味深长的眼神、停顿、收回的手：旁人起了疑或动了情，拿一个不说破的动作代替说出口的话；
   - 该长的话掐成半句，或一问一答也硬塞理由撑长；
   - 句句“某某道：”再接一句话，短话也用领起，读起来板；
   - 几个配角说话一个腔调，换了名字分不出是谁；
   - 神态词重样：急、气、哭、慌一章里翻来覆去，没有一个笑、一个“神情一松”；
   - 手上小动作堆砌：攥、搓、跺、拍、扒一章用了一串，眼睛和脑袋却没动过（第一之三节）；
   - 秃句白描：叙述段只剩一个动作；人出场没有衣着；到了新地方不环顾；物件没有颜色和材质。
   - 主角性格：嘴上抖机灵、连着耍嘴；决定没有来由，性子忽东忽西；往老道士靠的地方由叙述者点破，或主角当场就察觉，或拿“吓出来的毛病”“累的”搪塞过去（第一之六节）；
   - 时辰钱数：村里人张口“申正”“两刻”；主角嘴上说出“米”“分钟”；只写“付了钱”不写价钱；同一章里反复换算银钱；写阿拉伯数字（第一之五节）；
   - 讲设定：叙述者出来讲门派、衙门、历史；配角把自己不该知道的讲全；新名词一出就解释到底；村里人嘴里说出“死律”“亡鬼”这类作者的名目（第五之五节）；
   - 金手指一露面就整页交代：规矩、破法、来历一口气给全，主角立刻看懂、立刻会用，没怕、没盘算、没试错（第五之四节）。

## 九、写完自检

1. 拿原著同类的一段对着读，口吻像不像：平实、半文半白、爱打趣？
2. 逐段数句号：叙述段、对话段是不是都一段一句？段首短句后面有没有接着写？
3. 写人的地方，是不是直接交代了神情情绪，而不是一串慢镜头？动作是不是多在脸上、眼里、脑袋上，手在干活？攥、搓、跺、拍数一数。神态词有没有重样（急、气、哭、慌）？有没有笑，笑分没分种类？
4. 比喻数一数，超过三处删（打斗章放宽，但只用现成说法）。

7. 景物是在交代信息，还是在铺气氛？恐怖是不是只放在异象那几处？
8. 过场有没有一笔带过？这一笔有没有写满？
9. 白描：叙述段中位有没有到 30 字上下、超过 40 字的有没有三成上下？人出场有没有衣着、头发、长相、一句总评？衣冠名目合不合明末？名字出来前是不是拿最显眼的特征称呼？到新地方有没有环顾、按方位点实物、交代天色？物件有没有颜色材质？民俗流程有没有写到手上的东西和次数？
10. 对白：有没有光秃秃的“说：”？挂提示语的对白前后有没有写人？话的长短合不合这个人此刻的处境？短话是不是多用先说后补？话里带出的新名目，后面有没有人拆它？
11. 多人场面：谁对谁说清不清楚？不说话的人有没有一句在干什么？有没有把读者看过的事再说一遍？
12. 口吻：每个配角对主角的称呼是不是固定的？把名字遮住，读得出是谁在说吗？土词一个人一场戏有没有超过一两处？主角嘴上有没有土词？
13. 有没有破折号、氛围标签、天降认知？查一遍原著不用的词。
14. 有没有一处前埋后翻？章纲列的伏笔埋下时，是不是平常场面、配了一个说得通的解释、没点破？收线的章有没有复述当时的细节？有没有攒下一点暖意，或让一件旧物件带着情绪回来？
15. 每个出场的人刚经历了什么，身上还剩多少？
16. 有打斗的章：一招一段、写到结果？有来有回？跟人打有没有交底，主角赢得难不难看？跟死律挣命有没有土法灵与不灵、旁人各干一件、脱身后先查人？斗法有没有写出怎么做、施术人身上变了什么、效果打了多少折扣？
17. 白泽图出现的章：头一回是不是只给一眼、先见字再认出？显的字是不是只有类别和规矩、挑了几条？主角有没有先怕后看、喜后浇冷水？试规矩有没有每步一个结果、有代价？
