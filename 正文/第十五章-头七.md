# 第十五章　头七

> 按 `.claude/skills/wuzei-style`（项目技能）写，照 `01-大纲/第1卷-章纲.md` 第015章，接 `第十四章-湿墨.md`。★声音：湖里传来奶奶的声音叫赵黑娃，他死死攥住赵黑娃的胳膊，那声音最后改口叫大胆（章纲）。江伥叫名、应者溺（`鬼.md` 水鬼条；第十四章“溺”页）；货郎说过头七后人在湖里要叫名字（第十章）。回收第五章：奶奶那句“粥要是不够，晚上再来家里吃”，和缢鬼借大胆嗓子挨家敲门，这回换湖借奶奶的嗓子。赵家娘摆碗开门、揭符未成为本稿暂拟。

　　日头落下去以前，他跟着赵黑娃去了赵家，走得慢，两条腿还是软的，一步一步像踩在棉花上，赵黑娃在旁边扶着他一只胳膊，扶了半条巷子，叫他甩开了，他自己扶着墙走，墙皮叫他摸掉了一路。

　　路过葛婆婆家，老太太站在自家门里头，门只开了一道缝，她从缝里看着他们俩走过去，叫住了赵黑娃，说头七回煞，老辈人的规矩是躲，家里人躲进里屋，蒙上头，听见什么都别出来看，你娘要开门等，开门可以，人不许站在门口，说完，那道门缝就合上了，门闩落下去，咔哒一声。

　　赵家的院门大开着，门槛外撒了一道灶灰，撒得很厚，撒得很齐，拿扫帚把边上都扫平了，堂屋的门也开着，门板上那张罔两符还贴着，虎头朝外，底下那个角有一点卷。

　　院子当中那口缸还压着磨盘，磨盘边上搁着一只小板凳，板凳面叫人坐得发亮，凳腿边上的土里有两个浅浅的坑，是一双脚长年蹬在那儿蹬出来的，这几天赵黑娃的娘就坐在这儿，白天坐，夜里也坐，今天板凳是空的。

　　赵黑娃的娘在堂屋里摆碗。

　　桌上一只粗瓷碗，碗沿有个豁口，碗边横着一双竹筷，筷子头冲着门，她摆好了，看了看，拿起筷子来在衣襟上擦了擦，又摆下去，摆下去又觉着歪，又拿起来，摆到第四回，才把手缩回袖子里。

　　碗里是半碗粥，稀得照得见碗底，上头漂着几粒米，她拿勺子往碗里又撒了一小撮盐，盐粒落进去，沉到了碗底。

　　朱希言站在门口看着那一撮盐，那天早上，也是这样一碗粥，咸得刚好，一直暖到他肚子里。

　　赵黑娃的娘看见他，站起来，两只手在围裙上搓着，眼睛往他脖子上看了一眼，又挪开了，挪到门板上那张符上，她走过去，伸手去揭那个卷起来的角：

　　“这个得揭了，贴着这个，她老人家进不来门。”

　　赵黑娃一步跨过去，攥住了她的手腕，攥得她那只手在符边上停住了，指头还捏着那一角黄纸，母子俩谁都没说话，一个往下揭，一个往回拽，那一角黄纸叫两个人扯着，扯得绷直了。

　　朱希言靠在门框上，嗓子还哑着：

　　“婶子，符贴着，门开着，她要回来认家，就站在门口认，门口也是家。”

　　赵黑娃的娘手上松了劲，转过头看他，嘴唇抖了两下，那一角符纸从她指头缝里滑出去，啪的一声贴回了门板上，她没再去揭，回到桌边坐下，两只手拢在袖子里，眼睛盯着那只碗。

　　他挨着门槛，在门里头的地上坐下，赵黑娃坐在他边上，两个人都背靠着门框，脸朝着院子，朝着院门，朝着院门外那道灶灰。

　　他跟赵黑娃说，今夜不管听见谁叫，叫谁，谁都别应。

　　赵黑娃没问为什么，只是点了一下头，他又转过脸去跟堂屋里说了一遍，赵黑娃的娘坐在桌边，没点头，也没摇头，袖子里的两只手拢得更紧了。

　　他没跟他们说那张湿墨写的纸，说了也没用，他们只知道一句应了是人，他得让他们记住另一句。

　　天黑透了，桌上那盏油灯里只剩一层底，赵黑娃的娘不许添，说添满了，火太旺，老人家怕亮。

　　赵黑娃坐在他边上，隔一会儿就往院门外看一眼，看了几回，小声跟他说起小时候，说他小时候野，一到后晌就往湖边跑，摸螺蛳，掏鸟蛋，玩到天擦黑都不回来，奶奶就站在村东头那棵老柳树底下，两只手拢在嘴边，冲着湖那边喊，喊他回家吃饭，一喊，他就往回跑，跑得一身泥，奶奶也不骂，拿袖子给他擦脸，说咸粥在锅里焖着。

　　一更。

　　巷子里没有人走动，家家户户的门都闩着，只有赵家这一扇开着，灯光从门里淌出去，淌到院子里，淌到那道灶灰上，灰白得发亮。

　　二更过了一半，朱希言觉出了不对，是凉，从门外往里灌的风，这些天夜里是没有风的，一丝都没有，闷得人躺不住，这一阵风是从东边来的，贴着地皮，凉的，湿的，吹在脚脖子上，像是有人拿一块湿布在那儿擦了一下。

　　油灯的火苗往屋里倒了一倒。

　　然后，他听见了。

　　很远，是从东边来的，从湖那边，隔着好几十户人家的屋顶，一声，拖着，像是有人站在很远的地方，两只手拢在嘴边，往这边喊，喊的是黑娃。

　　赵黑娃的后背一下子离开了门框。

　　那声音又来了一回，还是那么远，不近也不远，可这一回听得清了，是个老太太的嗓子，豁着牙，黑字出口的时候漏着风，漏出来一点嘶嘶的气，娃字拖在后头，拖到尾巴上，咕的一声，像是嘴里含着一口水，话从水里头冒出来的。

　　赵黑娃小时候听了多少年的那一声，就是这个嗓子，这几个字，从老柳树底下喊到湖边，如今掉了个个儿，从湖边喊回了村里。

　　“黑娃，回家吃饭。”

　　堂屋里，赵黑娃的娘一下子站了起来，板凳倒了，砸在地上，她站在桌子后头，两只手撑着桌沿，脖子往门外伸着，嘴张开了。

　　朱希言扭过头去，冲着她，一个劲地摇头，摇得脖子上那两道勒痕扯着疼，她看着他，嘴一点一点合上了，一只手从桌沿上抬起来，把自己的袖子塞进嘴里，咬住了。

　　赵黑娃已经站起来了。

　　朱希言一把攥住他的胳膊，攥在胳膊肘上头，两只手一上一下攥死了，赵黑娃往前挣，挣了一下，没挣动，他那二百斤的身子往地上一坐，就是一扇磨盘，赵黑娃拖着他往前挪了半尺，挪不动了，就那么站着，胳膊在他手里绷得像一根弓弦。

　　湖那边的声音不紧不慢，一声一声地来：

　　“黑娃，粥熬好了，咸的，你爱吃咸的，奶奶给你搁了盐。”

　　赵黑娃的胳膊在他手里抖，抖得他两只手都跟着抖，他低着头，看不见赵黑娃的脸，只看得见他的脚，那两只光脚在地上抠着，脚趾头一根一根抠进了土里。

　　“黑娃，你咋不应奶奶，奶奶在湖边上站了七天了，脚底下凉，你来接奶奶。”

　　赵黑娃的嘴张开了，朱希言听见他喉咙里咯的一声，是一个字已经顶到了舌根上，他腾出一只手，照着赵黑娃的后腰狠狠拧了一把，拧得指甲都陷进了肉里，赵黑娃浑身一弓，那个字噎了回去，变成了一声抽气。

　　赵黑娃低下头，一口咬在自己的下嘴唇上，咬得血顺着下巴往下淌，滴在朱希言的手背上，是热的。

　　堂屋里，赵黑娃的娘咬着袖子，整个人顺着桌腿往下滑，滑到了地上，蹲着，肩膀一抽一抽，没有声音。

　　巷子那头，不知道谁家的门闩响了一声，拔出来半截，停住了，又一点一点推了回去，推回去以后，那户人家里有个孩子哭了一声，才哭出半声，就叫人捂住了。

　　湖那边停了。

　　停了很久，久到油灯的火苗又直了起来，久到赵黑娃胳膊上那股劲一点一点松了，朱希言攥着他的手也松了一点，手心里全是汗，汗把赵黑娃那截胳膊攥得滑腻腻的。

　　风也停了，脚脖子上那块湿布一样的凉，慢慢退了下去。

　　他坐着没动，把刚才那一阵在心里过了一遍，那个嗓子从头到尾都在东边，没往这边挪过一步，门槛外那道灰上没有印子，门板上那张符也没翘过角，它不用来，它站在湖边上，借一副嗓子，叫一个名字，等人自己应，应了，人自己就走过去了，跟那缸水一个样，摆在那儿，等你伸手。

　　他这才觉出自己的腿在抖，两条腿搁在地上，膝盖一跳一跳，按都按不住，他把手从赵黑娃胳膊上挪开，按在自己膝盖上。

　　院门外那道灶灰，平平的，白白的，没有印子。

　　朱希言张开嘴，想跟赵黑娃说一句过去了，话还没出口，东边又来了。

　　还是那个嗓子，豁着牙，漏着风，还是那么远，可这回叫的不是黑娃：

　　“大胆。”

　　他张着的那张嘴，一下子僵住了。

　　“大胆，粥要是不够，晚上来家里吃，你小时候最馋奶奶的咸粥，缸里的水甜得很，不用省着。”

　　一个字都不差，跟那天早上坐在他门槛上说的一模一样，连说到咸粥的时候那一声笑都是一样的，那一声笑从湖边上过来，过了几十户人家的屋顶，落进这间堂屋里，落在他耳朵边上。

　　他喉咙里一热，嗓子眼里有个东西往上顶，顶到舌头根上，是一个嗯，那天早上他端着碗，就是嗯了一声，低头喝的那一口，那一声嗯，他这辈子应过千千万万回，应得比吸气还快。

　　他死死咬住了后槽牙，咬得腮帮子上的肉一跳一跳。

　　他攥着膝盖的那只手上，搭上来一只手。

　　是赵黑娃的手，湿的，全是汗，一把攥住了他的胳膊，攥在胳膊肘上头，攥得死死的，跟他刚才攥他一个样，赵黑娃嘴唇上的血还在往下淌，说话的时候漏着气，一个字一个字往外挤，声音压得只有他一个人听得见：

　　“大胆，别应。”

　　湖那边，那个嗓子又叫了一声大胆，这一回，比刚才近了一点。
