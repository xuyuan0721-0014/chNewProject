# 第一章　应声

> 按 `.claude/skills/wuzei-style` 写，骨架仿《剑烛大荒》第一章《晓梦》：梦中黑暗 → 被一个声音牵出来 → 穿越前一幕与吐槽 → 醒来错认处境 → 认出身子不是自己的 → 盘算“说一半真话” → 对方要他证明 → 名字落地。与原章相反处：说真话在这里不管用，忘了名字就是被勾了魂。穿越方式按 `典籍.md`：古玩城见白泽图而穿越；摊上的经折册子“页面空着、只剩题字”对应“图对他是空的”，为正文暂拟。穿越前“只看不买”的性子与“一百三十来斤”“房贷”为暂拟。袖口石灰味接第五章，脖子一圈酸疼接第六章，结尾两声应和接第二章，均不改。

　　朱希言觉得自己胸口上压着一扇门板，不，比门板还沉，像是谁把一整袋水泥扛了上来，往他身上一撂就走了，压得肋骨咯吱咯吱响，一口气吸到半截，就怎么也吸不进去了。

　　四下里黑得什么都看不见，又冷又湿，只有远处立着一排细长的影子，一动不动，像一队排着号、等人叫名字的人。

　　嗒。

　　一滴凉水落在他脸上，顺着颧骨滑进了耳朵眼，凉得他一激灵，糊成一团的脑子里总算透进来一点亮。

　　这是在哪……做梦？鬼压床？我昨晚干什么了？

　　念头刚冒出来，先前的事就一股脑地涌了上来：周末，古玩城，二楼最里头那个摊子，一本摊开的旧册子。

　　朱希言在心里狠狠骂了一句。

　　他这个人别的本事没有，就讲究一个稳字，逛古玩城向来只看不买，连价都不问，因为他早听人说过，问了价就走不脱了，摊主能拽着你的袖子从八千讲到八百，讲到最后，你自己都觉得不买对不起人家。那天是同事硬把他拖去的，他跟在后头转了一上午，一件没摸，一句没问，稳得像是来视察工作的。

　　结果就在最后一个摊子上，他多看了一眼。

　　那是一本泛黄的经折册子，摊在玻璃柜台上，拉开来足有一丈多长，一折一页，每页顶上都用小篆题着一行字，页面上却干干净净，什么都没画。摊主说这叫白泽图，黄帝画的天下鬼怪，一万一千五百二十种，一个不少，就是年头太久，画都褪没了，只剩下题字，八百块，看在是熟客的面子上……

　　朱希言压根就没来过这个摊子，这个“熟客”也不知道是从哪儿论起来的，他就是凑近了些，想看清其中一页是不是真的什么都没有。

　　然后，那一页就黑了，黑得像一口井，他连往后退半步的工夫都没有，就一头栽了进去。

　　我就看了一眼！价都没问！看一眼也要收钱的吗？

　　……不对，现在不是算账的时候，先醒过来再说，醒过来说不定就躺在古玩城的地上，摊主正掐着我的人中，他要是顺手讹我八百块，我可一分都不认……

　　嗒。

　　又是一滴，这回落在眼皮上。

　　朱希言顺着那点凉意往上挣，挣一下，胸口那扇“门板”就轻一分，挣到第三下，远处那排影子淡了下去，黑暗像是被人从边上掀起了一角，漏进来一片发红的光，还有人说话的声音，隔着一层什么东西，闷闷的：

　　“黑娃，你摸摸，看他还有没有气。”

　　“人是你撺掇来的，你怎么不摸？”

　　“我同他又没你好……再说，他要真凉了，那五十文……”

　　“田六，你还有脸提那五十文？这是人话吗？”

　　先开口的那个不吭声了，只传来一阵窸窸窣窣往后缩的动静。

　　紧接着，一根带着泥的手指头伸了过来，戳进了朱希言的鼻孔。

　　朱希言猛地睁开了眼睛。

　　一张圆脸正俯在他上方，粗眉毛，黑脸膛，十六七岁的样子，头上胡乱包着一块蓝布，那根手指头还停在他鼻子底下，两个人大眼瞪小眼，谁也没动。

　　后头一声怪叫，一个瘦得像根竹竿的少年连退了好几步，被一座坟头绊了个仰八叉，两只手全撑进了烧剩的纸灰里。

　　朱希言顾不上他，眼珠子先转了一圈。

　　坟，一座挨着一座，高的齐腰，矮的只剩一道土棱，一直铺进后头的林子里去；坟前的石头上糊着被雨泡烂的纸钱灰；插坟的柳枝蔫了，叶子卷着；林子里的树上挂着清明没收的白幡，湿透了，贴在树干上一动不动，刚才梦里那一排影子，多半就是它们；不远处一座坟塌了半边，露出一角发黑的棺材板，板前一只豁口的粗碗，碗底干干净净，一粒米都没剩；日头压在西边山脊上，只剩半张脸，把林子里的空当照得通红。

　　而他自己，躺在一个土坑里。

　　没有柜台，没有玻璃，没有摊主，也没有古玩城。

　　“剧组？拍鬼片的？……不对，群演再敬业，也不会往人鼻孔里戳指头……”

　　“被人埋了？讹不成八百块，就把我拉到郊外埋了？……那也犯不着挑这么个清明刚过的坟地，还专门给我挖个坑……”

　　朱希言在心里一条一条地过，过到后来，自己先没了底气。

　　圆脸少年这时回过神来，脸上一下子涌起了喜色，一把抓住他的胳膊，又惊又喜地嚷道：

　　“大胆！大胆你能听见不？”

　　大胆？谁是大胆？……朱希言没答，低头去看那条被抓着的胳膊。

　　粗，白，肥，被那只手一抓，陷下去一道肉坑。他顺着胳膊往下看，湿透的粗布短褂裹着一个滚圆的肚子，腰带勒进肉里，只露出窄窄一截，领口里往外冒着一股酸苦的酒气，袖口里又钻出一股冲鼻子的石灰味。

　　他把另一只手举到眼前，翻过来，翻过去，手背上一排肉窝，指头又短又粗，指甲缝里全是黑泥。

　　这不是我的手……

　　我原本也就一百三十来斤，这一身肉，少说二百斤！谁给我换的？能退吗？

　　朱希言撑着坑沿坐起来，肚子上的肉跟着晃了两晃才稳住，脖子底下一圈却酸得厉害，大概是在坑里趴久了硌的。他就这么坐在坑里，看看这两个少年，又看看这满山的坟，那点“说不定是剧组”的侥幸，一点一点地凉了下去。

　　穿越……

　　网上那么多人天天喊着要穿越，要当王爷，要当首富，怎么偏偏轮到我这个逛古玩城只看不买的人？还是穿到坟地里，穿进一个二百斤的胖子身上！

　　我房贷才还了三年啊……

　　嗯，这么一想，房贷好像也不用还了？

　　这个念头只让他松快了一下，就被他自己按了回去。稳住，稳住……先把眼下的事想清楚。

　　他刚才趁着发愣，把这副身子里里外外摸了一遍，没摸到半点原主的记忆，这胖子叫什么、住哪儿、跟眼前这两个少年是什么关系，统统一片空白。

　　装，是装不像的。人家从小跟这胖子一块儿长大，说话什么腔调，走路先迈哪条腿，哪年摔断过哪根骨头，全都门儿清，自己两眼一抹黑地去演，演一句错一句，错一句就得再编一句去圆，圆到后来，迟早露馅。

　　那就说一半真话，只说什么都不记得了，磕了头也好，喝多了酒也好，让他们自己去找说法，人总是更信自己找出来的说法……

　　稳！

　　朱希言打定了主意，抬起头，尽量让自己的眼神显得又茫然又诚恳：

　　“你是……？”

　　圆脸少年脸上的喜色收了一点，试探着问道：

　　“大胆，你不认得我了？我是黑娃，赵黑娃！”

　　朱希言缓慢地摇了摇头，然后问出了他觉得最要紧、也最稳妥的那一句：

　　“我什么都不记得了……我叫什么？”

　　赵黑娃抓着他胳膊的那只手，停住了。

　　那只手慢慢松开，缩了回去，赵黑娃盯着他看了好几息，身子一点一点往后挪，挪到坑沿才站起来，又往后退了半步，一直退到了瘦高个身边。

　　瘦高个早从纸灰里爬起来了，这时候一声不吭地钻进草丛，摸出一根桃枝，双手攥着，横在了胸前。

　　两个人并肩站在坑沿上，都盯着坑里，谁也不说话。

　　朱希言心里咯噔一下。

　　这反应不太对啊……人磕坏了脑子，不该是赶紧扶起来送郎中吗？怎么一个个跟见了鬼似的？

　　赵黑娃的嘴唇动了几下，眼睛没敢离开坑里，偏过头低声说道：

　　“六子，他连自个儿叫啥都忘了。”

　　田六把桃枝攥得更紧了，嗓子眼里挤出来的声音直打颤：

　　“我娘说过，在坟地里睡一宿，醒过来不记得自个儿叫啥，那是魂叫东西勾走了……身子里头，换了别的。”

　　身子里头换了别的……朱希言张了张嘴，差点笑出来，又没笑出来。

　　这话还真没说错！

　　可谁能想到，在这地方，忘了名字就等于丢了魂？我挑了半天，挑了个最稳的说法，结果一张嘴，偏偏说中了要命的那一半……

　　他脑子飞快地转了起来：这地方的人信这个，信得真真的，一个被认定“换了芯子”的东西，会落个什么下场？捆起来？泼狗血？拿火烧？还是干脆扔在这坟地里，让它回它该回的地方去？

　　哪一样他都不想试。

　　田六已经壮着胆子凑近了两步，桃枝举得高高的，嘴里念念有词，也听不清念的什么，念完一闭眼，一桃枝抽了下来。

　　啪！

　　朱希言的胳膊上顿时起了一道红印，疼得他一哆嗦，捂着胳膊又惊又怒地瞪过去：

　　“你打我干什么？”

　　田六睁开一只眼，先看那道红印，又看朱希言的脸，扭头冲赵黑娃急急嚷道：

　　“他喊疼！”

　　赵黑娃皱着眉头盯着那道红印，盯了半天，也拿不准主意：

　　“鬼挨了桃枝，该叫唤才对。”

　　“喊疼不就是叫唤？”田六急得直跺脚。

　　两个人为这个竟争了起来，一个说喊疼就是叫唤，一个说叫唤得是嗷的一嗓子，谁也说服不了谁。

　　朱希言捂着胳膊坐在坑里，听着这两个少年替他断人断鬼，心里略感荒谬地想着：这地方验人验鬼，灵不灵，全看谁嗓门大……

　　赵黑娃忽然想起了什么，一把按住田六的桃枝，抬手往西边一指：

　　“看影子！鬼没影子！”

　　三个人一齐低头。

　　一点残红斜斜地照过来，把朱希言的影子拉得老长，从坑底爬上坑沿，爬过田六的脚面，一直搭到后头一座坟包上。影子是有的，只是淡，淡得像是撒了一层灰。

　　田六像被烫着了似的，一下把脚抽了回去，嚷道：

　　“日头都快没了，影子作不得数！”

　　他往赵黑娃身边缩了缩，凑到对方耳朵边上，压着嗓子说道：

　　“黑娃，要真是换了芯子，那大胆就是……没了。赌是跟大胆打的，他在坟地里睡一宿，我输他五十文，可他人都没了，这五十文……”

　　话没说完，他自己先哽住了，眼圈一红，抬手抹了一把眼睛。

　　赵黑娃狠狠剜了他一眼，一句话都没说，推开他，往前一步站到了坑沿上，咬着牙，死死盯着朱希言：

　　“日头一落，吊颈槐那头就过不去了。大胆，我喊你三声，你要是还在里头，你就应我。”

　　叫魂？……朱希言愣了一下，随即明白过来。魂要是没走远，喊三声，它听见了，自己就会回来；身子里头要是换了别的东西，它不会应这个名。

　　应了，是人；不应，是鬼。

　　赵黑娃深吸一口气，嗓门拖得老长：

　　“朱大胆——”

　　朱希言心头猛地一跳。

　　朱？这胖子也姓朱？

　　大胆那两个字多半是个诨号，他不在意，可这个朱字……天底下姓朱的是不少，可一万一千五百二十页里偏偏黑了那一页，偏偏把他扔进一个姓朱的身子里，这未免也太巧了吧？

　　“朱大胆——”

　　第二声喊出去，林子里的乌鸦扑棱棱飞起一片，绕着树梢打转。

　　朱希言顾不上再琢磨了。朱大胆这个名字跟他原本半点关系都没有，可眼下这个节骨眼，就算对方喊的是张三李四，他也得应。

　　“朱大胆——”

　　第三声落了地，林子里一下子静了下来，乌鸦不叫了，风也停了，连贴在树上的白幡都不动了。

　　朱希言张开嘴，用这副陌生的、又粗又闷的嗓子，应了一声：

　　“哎。”

　　赵黑娃的肩膀一下子塌了下来，眼圈发红，田六攥着桃枝的手也跟着垂了下去，嘴一咧，不知道是要哭还是要笑。

　　朱希言刚松了半口气，还没来得及在心里夸自己一句稳，林子深处，吊颈槐的方向，就有人也应了一声：

　　“哎——”

　　又粗，又闷，拖着一点鼻音，跟他刚才那一声，一模一样。
