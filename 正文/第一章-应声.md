# 第一章　应声

> 按 `.claude/skills/wuzei-style` 写，照 `01-大纲/第1卷-章纲.md` 第001章（2026-09-23 信息差重排版）；动笔前读《剑烛大荒》第一、二章与作者样章 `第一章_日落莫回头.txt`，字句自拟。设定依 `主线.md` 第一节：坑是葛婆婆挖的，土不填、纸灰是给道士阴神引路的；里正晌午打发田六来寻，是葛婆婆让叫的；林子里应的那一声是绳借了大胆的声音。本章只摆实相，不揭。暂拟：同事老陈、古玩城地摊、经折册子；磨坊三碗酒；奶奶烙的杂面饼；田六娘讲的“换芯子要烧”；葛婆婆讲的“第四声”旧事。伏笔：新坑、纸灰、晌午才叫人找（第4、14、44章）；袖口石灰味（第7章）；脖子一圈酸（第2、25章）；身子僵凉（第25、39章）；同姓朱（待定）；叫魂三声（第53、55章）；“你不认得我了？”（第47章）。前埋后翻：他头一回听见的这副嗓子，结尾林子里应声的是同一副。

　　朱希言只觉得浑身发沉，胸口压得喘不上气，眼皮也抬不起来。

　　他想醒，醒不过来；想动，连根手指头都使唤不动。

　　鬼压床？

　　呱！

　　一声老鸹叫从头顶落下来，朱希言打了个激灵，昏沉里透进一线清明，先前的事随之涌了回来。

　　今天下午，他陪同事老陈逛古玩城。老陈迷上了盘手串，怕挨宰，非拉上他，说他长了一张“不好骗”的脸。

　　朱希言确实不好骗。他办房贷那年，把合同逐字看了三遍，看得业务员哈欠连天，最后指着一行小字，硬是抠回了半年的利息。

　　这样一个人，在一个地摊前停住了脚。

　　摊上摆着一本经折册子，封皮黑黄。摊主说这是白泽图，黄帝画的天下鬼怪，一万一千五百二十种。朱希言本来只想笑一声就走，可那册子不知怎么自己散开了一折，他就低头多看了一眼。

　　那一页骤然黑了下去，黑成一口井，井底有股劲往上吸。他一头栽了进去，最后听见的是老陈在身后喊他的名字，喊到一半，没了声音。

　　所以……我这是晕在人家摊子跟前了？

　　还是……没了？

　　不至于吧，我连价都还没问啊！

　　老鸹又叫了一声，隔得远了些。朱希言顺着那声音往外挣，眼前的黑褪了下去，透进一片发红的光，耳边跟着有了人声。

　　“黑娃，你摸摸，看他还有气没。”说话的人离得稍远，声音打着颤。

　　近处有人狠狠吸了下鼻子，扭头冲那边骂道：

　　“你咋不摸？人是你拿五十文激上山的！”

　　“我同他又没你亲……”远处那人被骂得矮了半截，越说声音越小。

　　一根沾着土的手指头伸了下来，哆哆嗦嗦，径直戳进了朱希言的鼻孔。

　　朱希言霍然睁眼。

　　坑沿上探着一张圆脸，黑脸膛，粗眉毛，两只眼泡哭得通红，那根手指头还杵在他鼻子底下。

　　两人对视了一息。

　　圆脸的嘴一咧，眼泪先滚了下来。他抽回手，照着朱希言的肩膀就是一拳，又哭又笑地骂道：

　　“你个憨货！一宿不回，早上都当你又睡哪个草垛去了。里正晌午才打发田六来寻，这岗子上的坑，我一个一个扒着看的！”

　　他身后有人怪叫一声。一个瘦高的后生连退几步，一屁股坐进了坑头一堆纸灰里。

　　朱希言这才看清自己在哪。

　　他躺在一个土坑里。坑挖得方方正正，四壁留着一道道铁锨铲过的印子，土是新翻的，还带着潮气。挖出来的土堆在坑边，一锨也没填回来。坑外是一片乱坟，排进林子里，林边树杈上挂着几面褪了色的白幡。西边的日头压在山脊上，只剩半张脸。

　　圆脸攥住他的胳膊一使劲，把他拽得坐了起来，随即愣了愣，皱眉看着他问道：

　　“你身上咋这么凉？”

　　“兴许是在坑里躺久了。”朱希言含糊答了一句。

　　这一坐，他浑身关节咯吱咯吱响了一串，手脚又凉又木，一时回不过血来。一个滚圆的肚子先在眼前颤了两颤。

　　他低头看去：粗布短褂箍着一身白肉，胳膊又粗又壮，手背一攥一个肉窝。领口有股隔夜的酒气，袖口里却钻出一股冲鼻子的石灰味，脖子上一圈又酸又僵，转一下头都费劲。

　　朱希言呆住了。

　　他一百三十来斤，打小就没胖过。

　　这不是我的身子……

　　穿越？

　　念头刚冒出来，他自己都觉得荒唐，可屁股底下的湿土、胳膊上那只手，哪一样都假不了。

　　房贷不用还了，代价是多了七十斤肉。

　　朱希言把这笔账过了一遍，一时竟算不清是赚是亏。

　　他扭头看向坑头。瘦高后生坐塌的那堆灰，原本码得齐齐整整，正对着他躺的这一头，灰边还压着几张没烧透的纸钱。

　　挖坑、烧纸，这是给死人办的事。可死人是要埋的，这坑却敞着……是埋到一半叫人撞见跑了，还是压根就没打算填？

　　再往下想，就要想到这胖子昨夜是怎么躺进来的了。朱希言暂且按住不想。

　　眼下更要紧的是另一桩：这胖子叫什么，跟这两人什么交情，他一概不知。装是装不来的，倒不如咬死了一句“想不起来”。

　　圆脸没留意他的神色，从怀里摸出个布包抖开，是半块杂面饼子，揣了一天，捂得温乎乎的。

　　“奶奶烙的。”他把饼子往朱希言手里一塞，脸上还挂着泪，嘴上照旧恶声恶气，“叫我找着你就给你，说你昨儿在磨坊灌了三碗酒，一口干的都没进肚。吃！”

　　朱希言攥着那半块温饼，不知怎的想起了老陈。

　　那边这会儿，有没有人也给他温着一碗什么？

　　他把这念头咽回去，冲圆脸张了张嘴，话到嘴边改了口，试探着问道：

　　“你是……谁？”

　　声音一出来，他自己先吓了一跳。那是一副又粗又闷的嗓子，带着浓重的鼻音，跟他原来的声音没有半点相像。

　　圆脸的笑僵在了脸上。

　　他盯着朱希言看了几息，嘴唇抖了抖：

　　“你不认得我了？”

　　朱希言迎着他的目光，老老实实摇了摇头：

　　“我想不起来了。”见对方眼圈又红了，他放轻了声音，“我叫什么？”

　　“朱大胆！”抢着回话的是坑外那个瘦高后生。他刚从纸灰里爬起来，屁股上一片黑，隔着老远冲圆脸挤眉弄眼，“黑娃，你听听，你听听！”

　　朱大胆……也姓朱？

　　朱希言心里咯噔一下。穿到一个同姓的人身上，是赶巧了，还是另有什么讲究？他把这一条也记下，跟坑和纸灰搁在一处。

　　两人一个喊“田六”，一个喊“黑娃”，朱希言一声不吭，先把名字对上了号。

　　田六没敢走近，站在两座坟中间，压低了声音对赵黑娃道：

　　“我娘说过，坟地里睡一宿，醒过来不记得自个儿名字的，是魂叫勾走了。外头的东西钻进去，顶着原来那张脸回来。”

　　他咽了口唾沫，眼睛瞟着坑里，又补了一句：

　　“这种换了芯子的，要捆起来烧。”

　　朱希言攥饼的手一紧。

　　要捆起来烧……

　　可我确实是换了芯子啊！

　　赵黑娃回头狠狠瞪了田六一眼，骂他胡咧咧，攥着朱希言胳膊的手却没松，眼睛在他脸上来回地看。

　　田六见状，从坟头边折了根桃枝，远远地递过来：

　　“你抽他一下。鬼怕桃，一抽就现形。”

　　赵黑娃犹豫了一下，接过桃枝，冲朱希言说了句“你忍着点”，抬手就抽在他胳膊上。

　　“疼！”朱希言叫出了声。

　　这一下是真疼，胳膊上的肉颤了几颤，立时鼓起一道红印。

　　赵黑娃松了口气，扭头冲田六嚷道：

　　“喊疼了，是人。”

　　“鬼挨了桃枝也叫唤！”田六不服气，伸长了脖子争道，“叫唤得比人还响！”

　　“那你说咋算？不叫唤是鬼，叫唤也是鬼？”

　　“那……那得看叫唤的是啥。他喊的是疼，鬼喊的是……”田六卡住了，他也没听过鬼挨抽喊什么。

　　两人一个坑里一个坑外，争得脸红脖子粗，挨抽的那个倒像是没他什么事了。

　　争不出个结果，田六一跺脚，从怀里掏出钱袋，数出一串铜钱，冲着坑里递过来：

　　“行，行！五十文！说好鸡叫我上山来验，我……我没敢来。你在这儿待了一宿，算你赢。”

　　朱希言还没伸手，那串钱在半空里又缩了回去。

　　田六攥着钱袋，眼珠子转了两转，讪讪地看向赵黑娃：

　　“可他要是换了芯子，这钱……给谁？”

　　赵黑娃被问住了，张着嘴，一时答不上来。

　　朱希言也被问住了。按理该给朱大胆，可朱大胆眼下是他，他又不是朱大胆……

　　五十文，好像也不值得为这个把命搭进去。

　　就在这时，林子里传来一阵吱呀声。

　　吱呀，吱呀，一下一下，不紧不慢，像是有根绳子吊着什么沉东西，在树杈上来回地晃。

　　朱希言循声望去。林子深处，一面白幡正被什么东西往下拽，拽一下，停一停，再拽一下。四下没风，别的幡都垂着。

　　那两人还在为五十文大眼瞪小眼，谁也没往林子里瞧。

　　朱希言张了张嘴，又闭上了。

　　刚说完换了芯子的要捆起来烧，这时候他指着林子说“你们看，那幡在动”……

　　他把目光收回来，低头咬了一口饼。饼子干得掉渣，嚼得腮帮子发酸。

　　赵黑娃抹了把脸，把桃枝往地上一插，转过身来盯着朱希言，沉声说道：

　　“叫魂。”

　　“叫魂？”田六一愣。

　　“老辈人的法子，魂丢在哪，就冲哪叫。”赵黑娃抬手指向林子深处，“他昨夜在那头过的夜，魂要丢，也是丢在那儿。我叫他名字，他应了，魂就回来了，是人；不应，就是……”

　　后半句他没说出口。

　　田六的脸色一下白了，往坟后缩了缩：

　　“冲吊颈槐那头叫？”

　　“不冲那头冲哪头？”赵黑娃瞪了他一眼，又转回来，一字一句地叮嘱朱希言，“葛婆婆说过，叫魂只能叫三声。早年村里有个孩子，三声没叫应，他娘不死心，叫了第四声。应是应了，可那孩子往后睡觉，眼睛再没闭上过。”

　　朱希言听得后脖颈发凉，看了他一眼，忍不住问道：

　　“那我要是三声都没应上呢？”

　　赵黑娃没吭声，只看了田六一眼。

　　田六看了看地上那根桃枝。

　　朱希言懂了。

　　应了是人，不应是鬼，是鬼就捆起来烧。可他既不是朱大胆，也不是鬼，这一声，到底该算哪一头的？

　　他飞快地盘算了一遍：不应，今晚就得进柴堆；应了，不过是替一个叫朱大胆的人答一声到。替人答到这种事，他上学那会儿干得不少，还从没失过手。

　　赵黑娃已经转过身去，面朝林子，两手拢在嘴边，扯开嗓子喊道：

　　“朱大胆！回来哟！”

　　喊声撞进林子，惊起几只老鸹。

　　叫一声应一声，还是叫完再应？朱希言拿不准，没敢出声。

　　“朱大胆！回来哟！”

　　第二声。田六已经退到一座坟后头，只露出半张脸。

　　“朱大胆！回来哟！”

　　第三声喊完，赵黑娃的嗓子都劈了。他没回头，背绷得紧紧的，拢在嘴边的两只手在抖。

　　朱希言吸了口气，冲着那个背影应了一声：

　　“哎！”

　　还是那副又粗又闷、带着鼻音的嗓子。

　　赵黑娃肩膀一松，猛地转过身来，脸上的泪还没干，嘴已经咧开了。

　　就在这时，林子深处，吊颈槐那头，也有人应了一声：

　　“哎。”

　　那嗓子又粗又闷，带着鼻音，跟他刚才那一声一模一样。
