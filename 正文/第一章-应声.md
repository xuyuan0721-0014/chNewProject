# 第一章　应声

> 按 `.claude/skills/wuzei-style` 写，仿《剑烛大荒》第一章《晓梦》的骨架：梦中黑暗 → 被一个声音牵出来 → 前世死法与吐槽 → 醒来错认处境 → 认出身子不是自己的 → 盘算“说部分真话” → 对方要他证明 → 名字落地。与原章相反处：说真话在这里不管用，忘了名字就是被勾了魂。接 `第二章-吊颈槐.md`，结尾那一声应和不改。穿越方式按 `典籍.md`：古玩城见白泽图而穿越；摊上的经折册子“页面空着、只剩题字”对应“图对他是空的”，为正文暂拟。穿越前“只看不买”的性子与“一百三十来斤”“房贷”为暂拟。

　　黑，湿，冷，四下里什么都看不见，只有一些细长的影子立在远处，一动不动，像一排站着等人的人。

　　有什么东西压在胸口上，沉甸甸的，压得人喘不上气。

　　嗒。

　　一滴凉水落在朱希言的脸上，顺着颧骨滑进耳朵眼里，让他打了个激灵，迷迷糊糊的脑子里总算亮起了一点东西。

　　这是哪儿……

　　我这是……做梦？

　　念头刚冒出来，先前的事就跟着一股脑涌了上来：周末，古玩城，二楼最里头那个摊子，一幅卷轴。

　　朱希言在心里狠狠骂了一句。

　　他这辈子别的本事没有，就一个稳字，逛古玩城向来是只看不买，连价都不问，因为他早听人说过，问了价就走不脱了，摊主能拽着你的袖子从八千讲到八百，讲到你自己都觉得不买对不起人家。那天是同事硬拉他去的，他跟在后头转了一上午，一件没摸，一句没问，稳得像个来视察工作的。

　　结果就在最后一个摊子上，他多看了一眼。

　　那是一本泛黄的经折册子，摊在玻璃柜台上，拉开来足有一丈多长，一折一页，每页顶上都用小篆题着字，页面上却是空的，干干净净，什么都没画。摊主说这叫白泽图，黄帝画的天下鬼怪，一万一千五百二十种，一个不少，年头太久，画都褪没了，只剩下题字，八百块，看在是熟客的面子上……

　　朱希言根本不是熟客，他只是凑近了，想看清其中一页是不是真的什么都没有。

　　然后，那一页就变黑了。

　　我就看了一眼！

　　我连价都没问啊！

　　朱希言想睁眼，眼皮却像被浆糊粘住了，想翻身，身上那样沉东西压得更紧，四肢软绵绵的，一点力气都使不上。

　　鬼压床……不对，这种时候还想什么鬼压床，先醒过来再说，醒过来说不定就躺在古玩城的地上，摊主正掐着我的人中，要是他顺手讹我一幅画钱，我可一分都不认……

　　嗒。

　　又是一滴水，这回落在他的眼皮上。

　　他顺着那点凉意往上挣，一下，两下，身上的分量渐渐轻了，远处那些立着的影子也跟着淡了，黑暗像是被人从边上掀开了一条缝，漏进来一点发红的光。

　　有人在说话，声音不大，隔着一层东西，闷闷的。

　　“黑娃，你摸摸，看他还有没有气。”

　　“人是你撺掇来的，你怎么不摸？”

　　“我同他又没你好……再说，他要真凉了，那五十文……”

　　“田六，你还有脸提那五十文？这是人话吗？”

　　先开口的那个不吭声了，只听见一阵窸窸窣窣的响动，像是有人在往后退。

　　紧接着，一根带着泥的手指头伸过来，戳进了朱希言的鼻孔。

　　朱希言猛地睁开了眼睛。

　　一张圆脸正俯在他上方，粗眉毛，黑脸膛，十六七岁的样子，头上胡乱包着一块蓝布，那根手指头还停在他鼻子底下，两人大眼瞪小眼，谁都没动。

　　后头一声怪叫，一个瘦得像根竹竿的少年连退了好几步，被一座坟头绊了个仰八叉，两只手全撑进了烧剩的纸灰里。

　　朱希言的视线越过那张圆脸，往后看了看。

　　坟，全是坟，坟包挤着坟包，高的齐腰，矮的只剩一道土棱，一直铺进林子里去，树上挂着湿透的白幡，贴在树干上一动不动，刚才梦里那一排影子，大概就是它们。

　　日头压在西边山脊上，只剩半张脸，把林子里的空当照得通红。

　　朱希言躺在一个土坑里，愣了好几息。

　　这是……殡仪馆的业务拓展到郊区了？

　　不对，殡仪馆不会把人扔坑里……剧组？拍鬼片的剧组？群演倒是挺敬业，补丁是真补丁，泥是真泥，那小子脸上的黑也不像化妆化出来的……

　　圆脸少年回过神来，脸上随即涌起一阵喜色，一把抓住朱希言的胳膊：

　　“大胆！大胆你能听见不？”

　　朱希言没答，低头去看那条被抓着的胳膊。

　　粗，白，肥，被那只手一抓，陷下去一道肉坑，湿透的粗布短褂裹着一个滚圆的肚子，腰带勒进肉里，只露出窄窄一截，领口里往外冒着一股酸苦的酒气，袖口里又钻出一股冲鼻子的石灰味。

　　朱希言盯着这条胳膊看了好一会儿，又把另一只手举到眼前，翻过来，翻过去。

　　手背上是肉窝，指头短粗，指甲缝里全是泥。

　　这不是我的手……

　　我原本也就一百三十来斤，这一身肉少说二百斤，谁给我换的？能退吗？

　　他撑着坑沿坐起来，肚子上的肉跟着晃了两晃，这才稳住，脖子底下一圈却酸得厉害，大概是在坑里趴久了硌的。不远处一座坟塌了半边，露出一角发黑的棺材板，板前摆着一只豁口的粗碗，碗底干干净净，一粒米都没剩。

　　没有公路，没有电线杆，也没有古玩城。

　　朱希言心里那点侥幸，到这里算是凉透了。

　　穿越了……

　　网上那么多人天天喊着要穿越，要当王爷，要当首富，怎么偏偏轮到我这个逛古玩城只看不买的人？而且还是穿到坟地里，穿进一个二百斤的胖子身上！

　　我连房贷都还没还完啊……

　　嗯，这么一想，房贷好像也不用还了？

　　朱希言在心里苦中作乐了一句，随即把念头拽了回来，开始盘算眼下最要紧的事。

　　他刚才趁着发愣，在这副身子里里外外找了一遍，没找到半点属于原主的记忆，连这胖子叫什么、住哪儿、跟眼前这两个少年是什么关系，统统一片空白。

　　装是装不像的。

　　人家从小跟这胖子一起长大，说话什么腔调，走路先迈哪条腿，哪年摔断过哪根骨头，全都门儿清，自己两眼一抹黑地去演，演一句错一句，错一句就得再编一句去圆，圆到后来，迟早要露馅。

　　不如说一半真话。

　　就说什么都不记得了，磕着了头也好，喝多了酒也好，让他们自己去找说法，人总是更信自己找出来的说法……这叫什么来着？稳！

　　朱希言打定了主意，抬起头，望向那个圆脸少年，尽量让自己的眼神显得茫然又诚恳：

　　“你是……？”

　　圆脸少年脸上的喜色收了一点，试探着问道：

　　“大胆，你不认得我了？我是黑娃，赵黑娃！”

　　朱希言缓慢地摇了摇头，然后问出了他觉得最要紧、也最稳妥的一句：

　　“我什么都不记得了……我叫什么？”

　　这话一出口，赵黑娃抓着他胳膊的那只手，僵住了。

　　那只手慢慢松开，缩了回去。

　　赵黑娃盯着他看了好几息，身子一点一点往后挪，挪到坑沿才站起来，又退了半步，退到了瘦高个身边。

　　瘦高个早从纸灰里爬起来了，这会儿一声不吭地钻进草丛，摸出一根桃枝来，双手攥着，横在胸前。

　　两个人并肩站着，谁也不说话，都盯着坑里。

　　朱希言心里咯噔一下。

　　这反应不太对啊……忘了事，不该是赶紧扶起来送郎中吗？怎么一个个跟见了鬼似的？

　　赵黑娃的嘴唇动了几下，声音发干：

　　“六子……他连自个儿叫啥都忘了。”

　　田六把桃枝攥得更紧了，眼睛一刻也不敢离开坑里，从嗓子眼里挤出一句：

　　“我娘说过，在坟地里睡一宿，醒过来不记得自个儿叫啥，那是魂叫东西勾走了……身子里头，换了别的。”

　　身子里头换了别的……

　　朱希言张了张嘴，差点笑出来，又没笑出来。

　　这话还真没说错！

　　可是，在这个地方，忘了名字就等于被勾了魂，这谁能想得到？我说一半真话，偏偏说中的就是要命的那一半！

　　他脑子飞快地转了起来：这地方的人信这个，信得真真的，一个被认定“换了芯子”的东西，会是什么下场？捆起来，泼狗血，拿火烧，或者干脆扔在这坟地里，让它回它该回的地方去……

　　天快黑了，他连下山的路都不认得。

　　就在朱希言发愣的工夫，田六壮着胆子凑近了两步，把桃枝举得高高的，嘴里念念有词，念完一闭眼，一桃枝抽了下来。

　　啪！

　　胳膊上顿时起了一道红印。

　　朱希言疼得一哆嗦，捂着胳膊，又惊又怒地瞪着他：

　　“你打我干什么？”

　　田六睁开一只眼，先看那道红印，再看朱希言的脸，扭头冲赵黑娃急急嚷道：

　　“他喊疼！”

　　赵黑娃皱着眉头，盯着那道红印看了半天，也拿不准主意：

　　“鬼挨了桃枝，该叫唤才对。”

　　田六急得直跺脚，拿桃枝点着坑里：

　　“喊疼不就是叫唤？”

　　两人为这事竟争了起来，谁也说服不了谁。

　　朱希言捂着胳膊，看着这两个少年吵架，心里略感荒谬地想着：这地方验人验鬼的法子，灵不灵，全看谁嗓门大……

　　赵黑娃忽然想起了什么，一把按住田六的桃枝，抬手往西边一指：

　　“看影子！鬼没影子！”

　　三个人一齐低头。

　　一点残红斜斜地照过来，把朱希言的影子拉得老长，从坑底爬上坑沿，爬过田六的脚面，一直搭到后面一座坟包上。

　　影子是有的，只是淡，淡得像一层灰。

　　田六像被烫着了一样，一下把脚抽了回去：

　　“日头都快没了，影子作不得数！”

　　他往赵黑娃身边缩了缩，声音压得极低，低得像是怕坑里的人听见：

　　“黑娃，要真是换了芯子，那大胆就是……没了。赌是跟大胆打的，他在坟地里睡一宿，我输他五十文，可他人都没了，这五十文……”

　　话没说完，他自己先哽住了，抬手抹了一把眼睛。

　　赵黑娃狠狠剜了他一眼，一句话都没说，推开他，往前一步站到了坑沿上。

　　“日头一落，吊颈槐那头就过不去了。”赵黑娃咬着牙，死死盯着朱希言，“大胆，我喊你三声，你要是还在里头，你就应我。”

　　朱希言先是一愣，随即明白过来。

　　叫魂……魂要是没走远，喊三声，它听见了，自己会回来；身子里头要是别的东西，它不会应这个名。

　　赵黑娃深吸一口气，嗓门拖得老长：

　　“朱大胆——”

　　朱希言心头猛地一跳。

　　朱？

　　这胖子也姓朱？

　　大胆那两个字多半是个诨号，他不在意，可这个朱字……天底下姓朱的人是不少，可自己偏偏就穿到了一个姓朱的身上，这未免也太巧了吧？

　　“朱大胆——”

　　第二声喊出去，林子里的乌鸦扑棱棱飞起一片，绕着树梢打转。

　　朱希言顾不上多想。应了，是人；不应，是鬼。朱大胆这个名字跟他原本半点关系都没有，可眼下这个节骨眼，就算对方喊的是张三李四，他也得应。

　　“朱大胆——”

　　第三声落了地。

　　林子里一下子静了下来，乌鸦不叫了，风也停了，连贴在树上的白幡都不动了。

　　朱希言张开嘴，用这副陌生的、又粗又闷的嗓子，应了一声：

　　“哎。”

　　赵黑娃的肩膀一下子塌了下来，眼圈发红，田六手里的桃枝也跟着垂了下去。

　　就在这时，林子深处，吊颈槐的方向，也有人应了一声。

　　“哎——”

　　又粗，又闷，拖着一点鼻音。

　　跟朱希言刚才那一声，一模一样。
