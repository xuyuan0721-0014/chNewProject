# 第一章　应声

　　朱希言睡得极沉，沉得像是被人按进了一口缸底。

　　身上压着东西，四肢发木，怎么挣都挣不动。

　　鬼压床？

　　他记得老陈说过，鬼压床的时候千万别睁眼，一睁眼，就能看见床头坐着个人。

　　那这眼，还睁不睁了？

　　呱！

　　一声老鸹叫落在头顶，朱希言浑身一震，于昏沉中挣出一线清醒，先前的事随之翻涌上来。

　　今儿下午，老陈要给他爹挑个砚台做寿礼，怕叫人当冤大头宰，特意把他拉去了古玩城。

　　朱希言砍价是一绝，菜市场的摊主见了他都要先把秤收起来，单位里谁买车买家电，都要请他去坐一坐镇。

　　砚台没挑着，老陈倒在一个地摊前蹲下了。

　　摊上摆着一本黑乎乎的经折册子，摊主说这是白泽图，黄帝叫人画的天下鬼怪。

　　朱希言在心里估了个价，三十，顶天了。

　　他刚要开口，那册子自己散开了一折，他瞥了一眼。

　　那一页黑成了一口井，没有底，他脚下一空，一头栽了进去。

　　老陈在身后喊他的名字，喊到一半，便没了声音。

　　晕了？还是……没了？

　　一本三十块的破册子，要了我的命？

　　价都还没还呢！

　　呱！老鸹又叫了一声，隔得远了些。

　　朱希言跟着那声音往外挣，身上那股沉劲退了下去，眼皮外头透进来一片暗红。

　　离得稍远的地方，有人哆哆嗦嗦地开了口：

　　“黑娃，你摸摸他，看还有气没有。”

　　近处另一人吸着鼻子，带着哭腔骂了回去：

　　“人是你拿五十文激上山的，要摸你摸！”

　　远处那人不敢吭声了。

　　过了片刻，一根手指头探了过来，哆哆嗦嗦地找了一阵，戳进了朱希言的鼻孔。

　　朱希言一个激灵，睁开了眼。

　　坑沿上探下来一张圆脸，黑脸盘，扫帚眉，两只眼泡哭得红肿，那根手指头还戳在原处。

　　两人都愣住了，一个忘了抽手，一个忘了出气。

　　圆脸先回过神，猛地抽回手，嘴一瘪，眼泪扑簌簌往下掉，照着他肩膀就是一巴掌，又哭又骂道：

　　“憨货，憨货！

　　“一宿没个影儿，早上都当你又在谁家草垛里睡死了，里正晌午打发田六来寻，这一坡的坑，我一个一个扒过来的！”

　　他身后怪叫一声，一个瘦高后生往后一蹦，脚底一滑，一屁股坐进了坑头的纸灰堆里，扬起一片黑灰。

　　朱希言趁这工夫，把四下看了一遍。

　　他躺在一个土坑里，坑挖得方方正正，四壁上全是铁锨铲过的印子，土色发湿，是新翻的。

　　挖出来的土就堆在坑边，一锨也没往回填。

　　坑外是一片坟地，大大小小的坟包一直排到林子边上，林边的树杈上挂着几面白幡，西边的日头已压到了山脊，只剩小半张脸。

　　圆脸抓着他胳膊往上一提，他才坐起半截，浑身骨节便咯吱咯吱响成一片，手脚冰凉发木，不听使唤。

　　圆脸抓着他的那只手一缩，嘀咕了一句：

　　“冰手。”

　　朱希言没搭腔，他的心思全在自己身上。

　　一个圆滚滚的肚子横在眼前，把粗布短褂撑得紧绷绷的，两条胳膊又白又胖，一攥拳，手背上便起一排肉窝。

　　领口有股酒气，袖口却有股呛鼻的石灰味，脖子上一圈又酸又僵，稍一扭头便扯着疼。

　　朱希言瞪着这个肚子，瞪了好几息。

　　他一米七五，一百三十斤，大学四年没胖过一斤……

　　这肚子是谁的？

　　……我的？

　　穿越这种事，朱希言从前只在小说里见过，看的时候还嫌作者编得不讲道理。

　　如今轮到自己，他头一个想起来的，是房贷不用还了。

　　第二个想起来的，是白捡了七十斤肉。

　　两相抵消，他竟说不上该高兴还是该难过。

　　他扭头看向坑头，瘦高后生坐塌了半边的那堆纸灰，原本码得方方正正，正冲着他的头顶，灰边上还压着几张没烧透的纸钱。

　　挖坑，烧纸，都是给死人预备的，可死人要埋，这坑的土为何一锨没填？

　　再往下想，就得想这胖子昨夜是怎么躺进来的，朱希言把这个念头按了下去。

　　眼下顾不上这些，他连这胖子叫什么都不知道，更别说这两人同他是什么交情。

　　装是装不像的，索性什么都推给“想不起来”四个字。

　　圆脸没留意他在想什么，从怀里掏出个布包，打开来，是半块杂面饼子，边上裂着口子，揣了一天，还带着他身上的热乎气。

　　“奶奶烙的。”圆脸把饼往他手心里一按，嘴上凶巴巴的，“说你昨儿就没着家，叫我寻着你先给你垫垫，吃！”

　　饼是温的。

　　朱希言攥着那半块饼，忽然想，老陈那边，这会儿有没有人也给他温着一碗什么？

　　这念头来得突然，他赶紧把它掐了。

　　他抬眼看着圆脸，斟酌了片刻，试探着问道：

　　“你是……谁？”

　　这一开口，朱希言自己先吓了一跳。

　　他这副新嗓音又闷又粗，带着浓浓的鼻音，于胸腔里嗡嗡地响，没有半分是他原来的声音。

　　圆脸的哭声停了，直愣愣看着他，嘴唇抖了几下：

　　“你不认得我了？”

　　朱希言迎着那双红肿的眼睛，轻轻摇了摇头：

　　“我想不起来了。”

　　见对方脸都白了，他顿了顿，放低嗓音问道：

　　“我……叫什么？”

　　坑外那瘦高后生抢着开了口，一边拍屁股上的灰，一边冲圆脸嚷嚷：

　　“黑娃，你听听，你听听，他连自个儿叫朱大胆都不记得了！”

　　朱大胆……也姓朱？

　　朱希言心头一跳，天下那么多身子，偏偏落进一个同姓的，这具身子莫非还挑人？

　　这事一时想不明白，他先记在了心里。

　　听两人你一句我一句地嚷，他也把名字对上了，圆脸叫赵黑娃，瘦高后生叫田六。

　　田六扭头看看坑里，脸色越来越白，扯着赵黑娃往后退了两步，压着嗓音道：

　　“黑娃，坟地里睡一宿，醒来连自个儿名字都忘了的，那是魂叫勾走了。

　　“外头的东西钻进去，顶着原来那张脸回来的！”

　　他咽了口唾沫，又补了一句：

　　“这号换了芯子的，要捆起来烧。”

　　朱希言攥饼的手一紧。

　　捆起来……烧？

　　他换的可不就是芯子！

　　赵黑娃甩开田六，骂了声“放屁”，回过头来，一双眼却在朱希言脸上来回地打量。

　　田六也不跟他争，四下里找了找，从一座坟头上撅下一根桃枝，远远地递过去：

　　“是人是鬼，抽一记就知道，鬼怕桃木。”

　　赵黑娃接过桃枝，看看朱希言，一咬牙，冲他胳膊上抽了一记。

　　“嘶……疼疼疼！”

　　朱希言叫得半点不掺假，胳膊上当即肿起一道红棱。

　　赵黑娃松了口气，扭头冲田六一扬桃枝：

　　“听见没，喊疼了，是人！”

　　“鬼也会装！”田六梗着脖子争道。

　　“那你说，鬼装疼图个啥？”

　　“图你心软，不抽第二下！”

　　赵黑娃叫他噎住了，举着桃枝，抽也不是，放也不是。

　　朱希言在一旁听着，默默把胳膊往身后藏了藏。

　　田六见赵黑娃犹豫，自觉占了上风，从怀里摸出个钱袋，抖出一串铜钱数了数，递向坑里：

　　“五十文，赌是你赢了。

　　“说好了鸡叫我上山来验，我……我没敢来。”

　　钱递到半截，他的手又缩了回去。

　　田六攥着那串钱，犹犹豫豫地看向赵黑娃：

　　“可他要真换了芯子，这钱给他，那不成了给那东西送钱？

　　“给那东西送钱，得拿黄纸包了烧，哪有往手里递的……”

　　赵黑娃瞪着他，一时竟不知道该从哪句骂起。

　　朱希言看着那串钱在田六手心里攥得死紧，心想这五十文要是真烧了，田六怕是比自己挨桃枝还疼。

　　就在这时，林子里传来一阵吱呀声。

　　吱呀，吱呀，一声接着一声，像有根绳子吊着什么重物，在树杈上来回地晃。

　　朱希言循着声音望过去，林子深处，一面白幡被什么往下一拽，停住，又是一拽。

　　四下没有风，旁边几面幡都垂着。

　　那两人还在为五十文较着劲，谁也没朝林子那边看。

　　朱希言张了张嘴，最后把话连同一口饼一起咽了回去。

　　刚说完换芯子要烧，他可不想这时候指着林子说瞧见了什么。

　　赵黑娃把桃枝扔了，蹲于坑沿，盯着朱希言沉声道：

　　“叫魂。”

　　田六脸色一变：

　　“天都快黑了……”

　　“天黑了更叫不回来。”赵黑娃没理他，伸手按在朱希言的头顶上，“我叫你，你就应，应了，魂就回窍了。

　　“葛婆婆说过，叫魂最多叫三声，从前有个娃娃，三声没应，他娘急了，叫了第四声，娃娃是应了，可往后睡觉，眼皮再没合上过。”

　　那只按在头顶上的手，有些抖。

　　朱希言心里也发毛，抬眼看着他问道：

　　“要是三声都没应呢？”

　　赵黑娃没吭声，田六的手摸向了腰间的火镰。

　　朱希言懂了。

　　应了是人，不应是鬼，是鬼就捆起来烧，可他既不是朱大胆，也不是鬼，这一声该不该应？应了，算不算骗鬼？

　　他只犹豫了一瞬，便拿定了主意。

　　骗鬼，总比被当成鬼烧了强。

　　赵黑娃吸了口气，按着他的头顶，扯开嗓子喊道：

　　“朱大胆，回来喽！”

　　喊声撞进林子，惊起一群老鸹，呱呱叫着飞远了。

　　朱希言张着嘴没敢出声，是叫一声应一声，还是叫满了再应，他拿不准。

　　“朱大胆，回来喽！”

　　第二声，田六已经缩到一座坟包后头，只露出两只眼睛。

　　“朱大胆，回来喽！”

　　第三声喊完，赵黑娃的嗓子已哑了，按在他头顶的那只手抖得厉害。

　　朱希言攥紧那半块饼，冲他应了一声：

　　“哎！”

　　赵黑娃的手一松，整个人往后一坐，咧着嘴，眼泪又下来了。

　　就在这时，林子深处，也有人应了一声：

　　“哎。”

　　应声的那人，用的正是他这副身子的嗓音。
