# 第一章 应声

　　有人在很远的地方喊他。

　　朱希言听不清喊的是什么，只觉得脖子上箍着一圈东西，越挣越紧。

　　他想抬手去摸，胳膊却像压在身子底下，半点也动不了。

　　“啊——”

　　一声老鸹叫从头顶落下来，那圈紧劲儿松了些。

　　是做梦了？

　　朱希言仍睁不开眼，先想起了古玩城的地摊。

　　老陈拉着他一路逛过去，嫌前几家开的价太高，蹲在一处摊前又看又摸，朱希言便去翻旁边叠着的旧书。

　　里头夹着一本焦黄的经折册子，没写书名，合起来只有巴掌宽。

　　他捏着一端，才拉开一折，露出来的那页却黑得连纸纹都看不见。

　　朱希言把册子拿近了些。

　　那上头不像沾了墨，倒像翻开了一处没有底的地方。

　　他多看了一眼，脚下忽然没了着落。

　　“希言，你——”

　　老陈的声音停在身后，像有人隔着半句话关了门。

　　朱希言心里一沉。

　　古玩行里看货别上手，这话听过多少回，轮到自己偏偏忘了。

　　“有气没？你去摸摸。”

　　这回说话的人离他很近，是个年轻男子，声音发虚。

　　“你咋不摸？拿五十文激他上山的是你！”另一个人骂道。

　　朱希言想说自己没事，先把他扶起来，嘴却张不开。

　　那两人还在争，忽然有一根手指探过来，直戳进了他的鼻孔。

　　他呛得猛吸一口气，眼皮终于掀开。

　　先映进眼里的是一张圆脸，两只眼睛红肿得只剩一条缝，脸上还挂着没擦净的泪。

　　圆脸后生愣了一下，随即咧嘴笑了，笑到一半又狠狠抹了把脸。

　　“憨货！俺还当你真没了！”

　　朱希言看着他背后的天。

　　天光白得晃眼，旁边是一截截土壁，锨刃留下的直印子从坑沿落到身侧，坑头的纸灰被收拢成齐整的一堆，灰边还压着一角没烧透的纸钱。

　　他躺在一个新挖的方坑里。

　　坑边的土都在，一锨也没填回来。

　　圆脸后生手撑着坑沿，语速快得像怕他再闭上眼：“你一宿没回，早上俺们还当你钻哪家草垛睡了。晌午里正打发田六来寻，俺跟他把这坡上的坑一个个扒着看，才瞅见你。”

　　田六就是另一人？

　　朱希言偏过头，看见坑沿还站着个瘦后生，手里攥着新折的桃枝，枝头两片嫩叶在太阳底下打蔫。

　　瘦后生往后退了半步，嘴里说着“醒了就好”，眼睛却一直盯着他的脖子。

　　朱希言撑地坐起，双臂发木，肩肘一动，关节接连咯吱响了几声。

　　他低头看见一截肥厚的手腕和鼓起来的肚子，身上穿着旧短褐，袖口传来一股石灰味。

　　脖子也酸，酸得像睡觉时压住了筋。

　　这不是我的手，更不是我的身子。

　　朱希言在大腿上拧了一把，疼得吸气，心口跟着跳快了几下。

　　古玩城没了，老陈没了，自己到了一个别人认得他、他却谁也不认得的地方。

　　那本册子到底是什么书？

　　坑、纸灰和纸钱摆在眼前，他暂时不想猜它们是替谁准备的。

　　他先往裤腰摸了摸，平常挂家门钥匙的地方，只有一根勒得很紧的草绳。

　　还能回去吗？

　　至少房贷不用还了。

　　朱希言苦笑了一下，低头看看自己身上少说多了七十斤的肉，觉得这笔买卖实在说不上划算。

　　圆脸后生已经蹲了下来，从怀里掏出半块饼，塞到他手里。

　　饼还带着一点暖，颜色发灰，边上夹着细碎的皮屑。

　　“俺奶奶烙的榆皮面，特意给你留着。你昨晚肯定没吃，先垫一口。”

　　朱希言接饼时碰到他的手指，圆脸后生的笑意又没了。

　　“你这手怎么凉成这样？”

　　“坟地里躺一宿试试，能不凉？”圆脸后生像是在回瘦后生的话，说完自己也有些不信，重新握了握朱希言的手背。

　　朱希言没急着抽回手。

　　这个人会为他哭，会把荒年里的一口饼留给他，眼下却同样在怕他。

　　上班那些年，他跟领导、中介、银行的人讲过不少实话，也吃过把话说得太满的亏；这里有两个人盯着，他最好只讲自己能讲明白的那部分。

　　“你是谁？”他问。

　　一开口，朱希言自己先怔了。

　　那嗓音又粗又闷，还带着鼻音，听着不像从自己的喉咙里发出来的。

　　圆脸后生把他的手放回饼上，瞪大了眼：“你不认得我了？”

　　“我想不起来了。”

　　这句话倒是真的。

　　圆脸后生看了他一阵，嘴角往下撇，刚止住的眼泪又冒了出来。

　　“俺是黑娃，赵黑娃。你小时候跟俺摸鱼掏鸟窝，谁家的墙没叫咱俩翻过？”

　　他说到最后，伸手在朱希言肩上拍了一下，力道不重，像是还要试试手底下的是不是活人。

　　朱希言咬了一口饼，粗糙的面屑粘在舌头上，喉咙里干得难咽。

　　他忽然想起老陈那半声没喊完的话，也不知道他这会儿回了家没有，家里有没有人给他留一碗热饭。

　　“那我叫什么？”

　　赵黑娃脸上的泪没落下来，先转头看田六。

　　田六把桃枝横在身前，声音一下高了：“你看，我说什么来着！坟地里睡一宿，连自个儿的名都不认得，魂叫勾走了。老辈人讲，外头的东西就爱趁这个空当钻进来，占着原先那张脸！”

　　“少胡说。”赵黑娃嘴硬，握着坑沿的指头却收紧了。

　　“俺胡说？今年旱成什么样了，他又躺在新坑里，叫旁人瞅见，还当是旱魃，扒出来烧了求雨！”

　　朱希言抬头望着他们。

　　田六说的是吓人的话，还是这地方真会这么办，他不知道。

　　桃枝忽地抽在他的小臂上，火辣辣的一道疼。

　　“疼！”朱希言一缩手，饼差点掉进土里。

　　田六见他喊出来，脸色松了松：“桃枝抽得疼，兴许是人。”

　　赵黑娃一把夺了枝子：“让你抽了吗？叫你挨一下，你也喊，难不成你就能证明自己不是鬼？”

　　“我又没说这准！”田六把枝子抢回去，转而摸向腰间的钱袋，摸出来又在手里攥了一会儿。

　　他解开袋口，一串铜钱叮当地碰在一起。

　　“这五十文，是俺昨晚跟你打赌许的。”田六把钱往坑里递，目光只敢落在那半块饼上，“说好鸡叫时俺上山验，俺……没敢来。”

　　赵黑娃抬手就要替朱希言接。

　　田六的手又缩了回去，钱串半途晃了一下。

　　“可他连赌了什么都不记得，这赌还作不作数？”

　　“人都差点没了，你倒记得这钱。”赵黑娃气得笑了一声。

　　朱希言看着那串钱，没伸手。

　　他昨晚究竟为什么上山，田六和赵黑娃都知道，眼下却不是追着问的时候。

　　坑外忽然传来“吱呀”一声。

　　朱希言循声看去，坡顶的老槐林边立着一面白幡，垂下的布条被什么东西一下一下往林里牵，竹竿却没动。

　　坡上晒得发白，近处连半片草叶都没摇。

　　“你看那边……”

　　他话说到一半，见赵黑娃正掰开饼边的硬皮往他手里送，田六忙着把钱袋扎紧，两人谁也没往林子看。

　　朱希言合上嘴，把目光移了回来。

　　白布还在眼角一摆一摆。

　　“你是朱大胆。”赵黑娃说得很慢，像教人认字，“大野村的守村人。平常俺叫你大胆，叫憨货，你听见就回头。”

　　朱希言点了点头，心里记下“守村人”三个字，没有当场问。

　　田六瞥了一眼他手里的饼，嘀咕道：“记不得事，也得先看看魂回没回全。”

　　“怎么个看法？”朱希言问。

　　赵黑娃抹干净脸，站到坑头，朝着坡顶那面白幡看了一眼，又移开目光。

　　“葛婆婆教过，丢了魂，就在倒下的地方叫他的名。喊一声，他答一声，叫回来才好领回家。”

　　“叫几声？”田六问。

　　“三声。”赵黑娃说，“最多三声。前些年有个娃子，前三声都不答，第四声才叫应了，后来夜里睡觉，眼睛再也没合上过。”

　　田六把桃枝抱在胸前：“三声还不答，就叫葛婆婆自己来认。俺可不敢把他往村里领。”

　　朱希言手里那半块饼仍是暖的，掌心却凉了下来。

　　我不是朱大胆。

　　应了，会怎样？不应，田六口中的“外头的东西”就是他。

　　赵黑娃把两手拢在嘴边，冲着坑里叫了一声：“朱大胆！”

　　朱希言望着他，一时没有出声。

　　赵黑娃的眼睛还肿着，叫完便侧耳等，等得田六把桃枝从左手换到右手。

　　“朱大胆！”

　　坡顶传来细小的吱呀声。

　　朱希言盯着赵黑娃，余光里那面白幡往林中斜了些。

　　“憨货，你答俺一声。”赵黑娃放下手，嗓子里有了哭腔，“就一声。”

　　田六忙说：“还剩最后一声，叫完别叫了！”

　　赵黑娃吸了口气，第三次朝着坑里喊：“朱大胆！”

　　朱希言攥紧饼，终于张了嘴。

　　“哎。”

　　赵黑娃的肩膀往下一垮，坐在了坑沿上。

　　同一刻，老槐林深处也应了一声：“哎。”

　　那声音又粗又闷，带着鼻音，和朱希言刚才开口时一模一样。
